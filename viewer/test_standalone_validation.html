🔍 Validation du mode Standalone - HTR Viewer

Tests automatiques

Versions du viewer disponibles

  • htr_viewer.html - Version originale (nécessite serveur)
  • htr_viewer_standalone.html - Version standalone avec fallback
  • htr_viewer_fully_standalone.html - Version 100% autonome avec données intégrées

📋 Recommandations

Pour un fonctionnement optimal sans serveur :

  1. Utilisez htr_viewer_fully_standalone.html qui intègre toutes les données
  2. Pour Chrome : lancez avec --allow-file-access-from-files pour permettre l'accès aux fichiers locaux
  3. Pour Firefox : modifiez security.fileuri.strict_origin_policy dans about:config (non recommandé)
  4. Solution recommandée : utilisez un serveur local simple avec python -m http.server 8000
